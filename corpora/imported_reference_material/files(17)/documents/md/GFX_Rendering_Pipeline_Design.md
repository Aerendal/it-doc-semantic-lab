## Document Sections

### 1. Executive Summary

Defines the detailed rendering pipeline stages from vertex input through final framebuffer output. Covers shader architecture, state management, and multi-platform compatibility layer.

### 2. Pipeline Overview

**High-Level Flow:**
```
Vertex Input → Vertex Processing → Primitive Assembly → Rasterization
    → Fragment Processing → Output Merge → Post-Processing → Display
```

**Stages:** 8 discrete pipeline stages with configurable bypass paths for mobile optimization.

### 3. Vertex Processing Stage

**Vertex Shader Operations:**
- Model-View-Projection transform
- Normal/tangent space transformation
- UV interpolation setup
- Skinning (blend weights, up to 4 joints per vertex)

**Attribute Layout:** Position (3×f32), Normal (3×f32), Tangent (4×f32), UV0-1 (2×2×f32), Color (4×u8), Joint indices (4×u16), Joint weights (4×f32)

### 4. Rasterization Configuration

**Triangle Assembly:** Back-face culling enabled by default (CCW winding).

**Interpolation:** Perspective-correct barycentric interpolation for all attributes.

**Early-Z:** Enabled for opaque geometry pass; disabled for alpha-tested geometry.

### 5. Fragment Processing

**Fragment Shader Pipeline:**
1. Texture fetch (base color, normal, roughness, metallic)
2. Normal map decode and TBN application
3. PBR lighting calculation (Cook-Torrance BRDF)
4. Shadow sampling (CSM cascade selection)
5. Environment reflection (IBL)
6. Output: final color + depth

### 6. Post-Processing Pipeline

**Pass Order:** TAA → Bloom → Motion Blur → Depth of Field → Tone Mapping → Gamma Correction

**Bloom:** Kawase blur approach with configurable threshold and intensity.

**Tone Mapping:** ACES filmRec709 for SDR; ST2084 PQ for HDR displays.

### 7. GPU State Management

**Draw Call Batching:** Instanced rendering for repeated geometry. Material state sorting to minimize bind changes.

**Resource Binding:** Descriptor sets (Vulkan) / CBV/SRV heaps (DX12) pre-bound per pass.

**State Transitions:** Barrier graph computed at scene setup; minimal runtime barriers.
