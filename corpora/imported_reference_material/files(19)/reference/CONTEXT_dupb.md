## Methodology

*IT Documentation Matrix Part 5 — Generated 2026-02-01*  
*Research-first methodology: internet research → database → sections → RACI → templates*

Pipeline:
1. **Internet Research** — Standards, frameworks, best practices per industry → `research/internet_research.md`
2. **Markdown Parsing** — Extract all documents from source → `scripts/parse_part5.py`
3. **SQL Generation** — Generate all SQL from parsed data → `scripts/generate_sql.py`
4. **Database Population** — Load schema + data into SQLite → `db/part5_doc_matrix.db`
5. **CLI Tool** — Query and report interface → `scripts/db_manager.py`
6. **CSV Exports** — Full matrix export → `exports/*.csv`
