## 1. CHANGE CATEGORIES

| Category | Risk | Approval | Lead Time |
|----------|------|----------|-----------|
| Standard | Low | Pre-approved | None |
| Normal | Medium | CAB | 5 days |
| Emergency | High | CISO | Immediate |

## 2. CHANGE PROCESS

### 2.1 Standard Flow
1. Submit change request
2. Security impact assessment
3. CAB review (if required)
4. Schedule implementation
5. Execute change
6. Post-implementation review

### 2.2 Emergency Flow
1. Verbal approval from CISO
2. Implement change
3. Document within 24 hours
4. Post-incident review

## 3. SECURITY IMPACT ASSESSMENT

| Question | Yes Impact |
|----------|------------|
| Changes firewall rules? | Security review |
| Affects authentication? | IAM team review |
| Modifies encryption? | Crypto review |
| Impacts logging? | SOC review |
