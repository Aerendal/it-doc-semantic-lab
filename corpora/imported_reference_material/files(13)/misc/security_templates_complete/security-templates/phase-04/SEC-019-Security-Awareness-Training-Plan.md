## 1. PROGRAM OVERVIEW

### 1.1 Objectives
1. Reduce human risk through education
2. Create security-aware culture
3. Meet compliance requirements
4. Reduce phishing susceptibility to <5%

### 1.2 Target Audiences

| Audience | Training Level | Frequency |
|----------|----------------|-----------|
| All employees | Foundation | Annual + quarterly |
| IT staff | Advanced | Quarterly |
| Developers | Secure coding | Quarterly |
| Executives | Executive briefing | Semi-annual |
| Privileged users | High-risk | Monthly |
| New hires | Onboarding | Day 1 |
