## 1. ONBOARDING CHECKLIST

### Week 1: Orientation
- [ ] Security team introduction
- [ ] Access provisioning (SIEM, EDR, ticketing)
- [ ] Security policies review
- [ ] Tool overview sessions

### Week 2: Tools Training
- [ ] SIEM hands-on training
- [ ] EDR platform training
- [ ] Ticketing system training
- [ ] Communication tools

### Week 3: Procedures
- [ ] Alert triage procedures
- [ ] Escalation procedures
- [ ] Shift handoff procedures
- [ ] Documentation standards

### Week 4: Shadowing
- [ ] Shadow senior analyst (day shift)
- [ ] Handle tickets with supervision
- [ ] Participate in incidents (observer)
