## Cel dokumentu

## Typowe problemy / rozwiązania

- Overfitting/brak generalizacji: za mało danych, brak walidacji → zwiększ dane, cross‑val, regularization, ogranicz feature leakage.  
- Feature leakage: cechy z przyszłości → leak checks, przesunięcie czasowe, usunięcie target leak.  
- Zła metryka: accuracy przy klasach niezbalansowanych → F1/AUC/PR-AUC, cost-sensitive metrics.  
- Imbalanced data: → class weights, oversampling/undersampling, appropriate metric.  
- Długi czas/koszt trenowania: za duży search space → ogranicz hyperparam space, early stopping, budżet czasowy/kosztowy.  
- Drift: produkcja odbiega od treningu → monitoring driftu, okna czasowe, harmonogram retrain.  
- Brak interpretowalności: → SHAP/perm importance, raport feature importance, limity na black-box przy compliance.
