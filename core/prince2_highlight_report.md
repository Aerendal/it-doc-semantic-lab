# Highlight Report (PRINCE2 7)

## Metadane
- Właściciel: Document Owner
- Wersja: v0.1
- Data aktualizacji: RRRR-MM-DD
- Status: draft | in review | approved


> Powiązania: linkage_index.jsonl

## Cel dokumentu
Dostarczyć Project Board regularne, zwięzłe raporty postępu etapu/projektu w ustalonych interwałach (Reporting Cycle) zgodnie z PRINCE2 7 — realizując zasadę Manage by Exception. Raport informuje o postępie, budżecie, ryzykach i problemach bez wymagania interwencji Project Board, chyba że identyfikuje zagrożenie tolerancji.

## Zakres i granice
Obejmuje: okres raportowania, postęp vs plan (kamienie milowe, praca wykonana/planowana), aktualny status tolerancji (czas/koszt), kluczowe ryzyka i problemy (z rejestru), planowane działania do następnego raportu, problemy wymagające decyzji.
Poza zakresem: szczegółowe dane techniczne dla Project Team (Stage Checkpoints), Exception Report (gdy tolerancje przekroczone).

## Wejścia i wyjścia
Wejścia: Stage Plan (aktualne), Checkpoint Reports od Team Managerów, Issue Register, Risk Register.
Wyjścia: Highlight Report przesyłany do Project Board (nie wymagany do zatwierdzenia, tylko do wiadomości).
