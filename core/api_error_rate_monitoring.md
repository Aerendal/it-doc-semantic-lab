## Cel dokumentu

Monitorować błędy API (4xx/5xx/429) i ich przyczyny, aby szybko reagować na degradacje.


## Zakres i granice

- Obejmuje: metryki błędów per endpoint/klient, korelację z auth/rate limiting, alerty, dashboardy, raporty.
- Poza zakresem: monitoring backendów nieeksponowanych (osobne dokumenty).
