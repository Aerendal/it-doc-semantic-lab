# Exception Report (PRINCE2 7)

## Metadane
- Właściciel: Document Owner
- Wersja: v0.1
- Data aktualizacji: RRRR-MM-DD
- Status: draft | in review | approved


> Powiązania: linkage_index.jsonl

## Cel dokumentu
Poinformować Project Board o sytuacji wyjątkowej (Exception) — gdy projekt lub etap przewiduje przekroczenie ustalonych Tolerancji (czas, koszt, zakres, ryzyko, jakość, korzyści) — zgodnie z zasadą Manage by Exception PRINCE2 7. Raport umożliwia decyzję Project Board: kontynuuj w ramach nowych tolerancji, zainicjuj Exception Plan lub zakończ projekt.

## Zakres i granice
Obejmuje: opis sytuacji wyjątkowej (co, kiedy, dlaczego), wpływ na cele projektu (tolerancje Business Case, czas, koszt, zakres), analiza przyczyn, opcje odpowiedzi (minimum 3 opcje z oceną ryzyka i kosztów), rekomendacja Project Managera.
Poza zakresem: szczegółowy Exception Plan (oddzielny dokument zatwierdzany przez Project Board), Highlight Reports (rutynowe raporty postępu).

## Wejścia i wyjścia
Wejścia: aktualne Stage Plan, tolerancje projektu/etapu, rejestr ryzyk i problemów (Issue/Risk Register), prognoza Stage Manager.
Wyjścia: Exception Report → decyzja Project Board → (jeśli zatwierdzono) Exception Plan.
