# High Error Rate Incident Response


## Metadane

- Właściciel: Security Officer
- Wersja: v0.2
- Data aktualizacji: RRRR-MM-DD

## Cel dokumentu

Playbook reagowania na incydenty podwyższonego error rate (HTTP 5xx/4xx kluczowe, gRPC errors, timeouts) w usługach – skrócić MTTR, chronić SLA/KPI i ujednolicić działania oraz komunikację.


## Zakres i granice

- Obejmuje: detekcję i progi alertów, triage (blast radius, klient/region), hipotezy i szybkie testy, rollback/feature flags, load shedding/rate limit, rerouting, zależności (DB/cache/queue/3rd party), komunikację (status page, CS, biznes), ewidencję i postmortem.
- Poza zakresem: pełny DR/BCP i incydenty bezpieczeństwa (oddzielne playbooki).


## Użytkownicy i interesariusze
- **CISO / Security Officer** — odpowiada za strategię bezpieczeństwa i akceptuje dokument
- **Security Engineer** — implementuje mechanizmy ochronne i przeprowadza testy
