## Struktura sekcji (szkielet)

1. Zakres: modele/use-case (audio/vision/IMU), urządzenia/testboards, wersje firmware.
2. Metryki: accuracy/F1, latency, memory footprint (RAM/Flash), energia/bateria, stabilność.
3. Scenariusze: dane realne/symulowane, warunki środowiskowe (hałas, oświetlenie), długość testu.
4. Narzędzia: profiling (TF Lite Micro/profiler), power measurement, logi, benchmarking scripts.
5. Kryteria akceptacji: progi metryk, regresja vs baseline, tolerancje.
6. Raport: wyniki, regresje, rekomendacje (quant/prune/arch), lista issue.
