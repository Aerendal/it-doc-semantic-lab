## Cel dokumentu
Zdefiniować proces ładowania modeli 3D w silniku docelowym: formaty, streaming/async, LOD, zależności (materiały/tekstury/anim), cache, kompresja, instancing i budżety pamięci, aby minimalizować czasy ładowania i szczytowe zużycie RAM/VRAM.

## Zakres i granice
- Obejmuje: import/export formatów (fbx/gltf), asset bundles/paks, dependency graph (materiały/tekstury/animacje), LOD i streaming, async loading i fallbacki, kompresję (geometry/texture), cache, versioning, hot-reload (jeśli), error handling, telemetry/perf.
- Poza zakresem: tworzenie modeli (w Model Creation/Design) oraz pipeline shaderów (oddzielne).

## Wejścia i wyjścia
- Wejścia: spec modeli/LOD, formaty eksportu, struktura asset bundle/pak, mapy i materiały, docelowe platformy (PC/console/mobile/VR), budżety pamięci i czasy ładowania, narzędzia importu.
- Wyjścia: spec ładowania (formaty, kompresja, streaming plan), konfiguracje importu, profile cache, checklisty QA perf/stability, metryki (time-to-first-frame, peak mem), procedury obsługi błędów.

## Struktura sekcji (szkielet)
- Format i import: wspierane formaty, scale/axis, tangent space, naming, automatyczne assign materiałów/tekstur/animacji.
- Bundlowanie i zależności: asset bundles/paks, dependency graph, priorytety ładowania.
- Streaming/LOD/async: strategia LOD, prefetch, streaming chunks, fallback (proxy/low LOD), time slicing.
- Kompresja i cache: geometry compression, texture compression, on-disk/in-memory cache, eviction, mip bias.
- Pamięć i performance: budżety RAM/VRAM, draw-call/instancing, metryki ładowania (TTFF, stutter), profiling narzędzia.
- Versioning/hot-reload: zasady aktualizacji assetów, zgodność wsteczna, walidacje.
- Error handling: missing deps, corrupt asset, retry, fallback, logging/telemetria.
- QA checklist: load tests (zimny/ciepły start), stutter, LOD popping, brakujących materiałów, memory spikes.
